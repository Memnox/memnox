# Changelog

What each release is, in one place. Per-package notes are generated by changesets into
`packages/*/CHANGELOG.md` from the release after this one; there is nothing to generate
for a first release, because there is no previous version to describe a change against.

Everything before 0.1.0 was a different product and is not listed here.

## 0.1.0

The first release. Everything below works; the version says this is the beginning
rather than a promise about stability.

### What it does

- **`memnox scan`** — what can act on this machine and what it reaches. Detects Claude
  Code, Claude Desktop, Cursor, Codex CLI, Cline and VS Code; enumerates MCP servers
  over the protocol rather than guessing from a config. `--tools`, `--mcp <server>`,
  `--usage 7d`, `--save`, `--share`, `--json`.
- **`memnox diff` / `watch`** — what changed, with `--fail-on` for CI. Alerts on a
  credential that became reachable, a new server, a new write tool, and an agent that
  updated itself and came back holding more.
- **`memnox protect`** — reversible hardening that prints the undo first, mode flags,
  and `--apply-native` to write the same rules into Claude Code's own permissions.
- **`memnox mcp wrap` / `run`** — route agents through the proxy and the interceptors.
  An `ask` rule holds the call at your terminal.
- **`memnox timeline` / `why` / `purge`** — what happened, why it was decided that
  way, and retention.
- **`memnox uninstall`** — takes it all back off.

### Guarantees

- No model on any path.
- Nothing here originates a network request, and there is no telemetry (ADR 0002). The
  only sockets are the daemon's unix socket and the egress proxy on loopback, which
  forwards the agent's own traffic after the gate has ruled on it.
- A secret value never leaves the process that read it — paths, kinds and digests only.
- The event ledger is append-only, enforced by a database trigger, and every seam
  writes to it — the shell, the PATH wrappers, the git hooks and the MCP proxy alike.
- Event schema v1 is frozen and published.

### Known limits

Named in `docs/threat-model.md` rather than left to be discovered. The largest: `PATH`
is advisory, so an agent invoking an absolute path never meets an interceptor. The OS
guard, the git hooks and the MCP proxy each close part of that.

Windows is WSL-only (ADR 0001).
